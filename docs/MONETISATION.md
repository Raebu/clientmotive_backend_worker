# Monetisation model

The backend supports a commercial ladder rather than one service.

| Layer | Product | Revenue model | System role |
|---|---|---|---|
| Free | Growth Snapshot / diagnostics / account watch | Lead generation | Captures intent and creates useful reciprocity |
| Entry | ICP Sprint / Competitive Sprint / Outbound Readiness Audit / Campaign Architecture | Fixed fee | Monetises prospects not yet ready for managed outreach |
| Core | ClientMotive Managed | Monthly / project | Managed research-led execution |
| Recurring | ClientMotive Intelligence | Subscription | Portfolios, signals, competitors, buyer changes, priorities and briefings |
| Premium | GTM Intelligence + Managed Execution | Retainer | Intelligence plus execution and account growth |
| Later | White-label Intelligence / Research API | Usage/SaaS | Agencies/partners consume selected capabilities |

## Revenue loops

### Inbound
content / industry page / diagnostic → value preview → growth brief → research → opportunity → paid sprint or managed engagement

### Outbound
market definition → account discovery → trigger → next-best account → evidence-led message hypothesis → outreach review queue → opportunity

### Recurring intelligence
client portfolio → watchlists → signals → priority changes → recurring intelligence brief → renewal / expansion

### Learning
campaign hypothesis → reply/meeting/proposal/win-loss → objection/outcome data → benchmark/scoring/content improvements

### Group opportunity routing
lead need → category classification → configured routing destination → human-approved referral → attribution

## Pricing guardrail

The backend can analyse historical won-deal values, but it deliberately does not auto-set prices. Scope, delivery cost, margin, risk and contractual commitments still require human commercial approval.
